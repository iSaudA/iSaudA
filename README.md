## Featured project

### [AYN AL-SIJILL: Azure observability with the Elastic Stack](https://github.com/iSaudA/elk)

Follow a synthetic checkout from payment authorization to a missing order. Correlated events connect the failure evidence across Azure Functions, Logstash, Elasticsearch, Kibana, and Azure SQL. Terraform defines the infrastructure. Built with my team through the SDA Cloud Computing Bootcamp.
